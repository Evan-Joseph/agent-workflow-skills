# 前端原型开发提示词

你现在要为一个已经存在的项目开发一套新的前端原型。

这份提示词只描述产品需求、页面结构、交互和状态边界，不限定你使用哪种AI前端工具，也不规定中间过程、输出格式或额外交付物。

## 目标

基于下面的页面说明，做一套可运行的前端原型。后续这套原型会直接接入现有后端，所以请把页面、结构、状态和交互设计完整，不要只做几张静态效果图。

## 总体要求

- 保持统一的视觉语言
- 页面结构完整
- 页面之间能正常跳转
- 所有主要控件都要有明确用途
- 必须覆盖常见状态，不要只做“正常态”
- 视觉细节要经得起真实使用：文字换行自然，圆角层级协调，图标和文字视觉重心正确，卡片/按钮/图片边缘干净，小控件好点，动态数字不抖动，动画可被打断

## 不要做这些事

- 不要做只有外观、没有页面结构的“截图型原型”
- 不要省略弹窗、空态、错误态、加载态
- 不要把明显可点击的控件做成无意义装饰
- 不要擅自减少页面
- 不要引入和项目无关的复杂功能
- 不要在需求提示词里附加和具体工具绑定的输出格式、源码说明、打包方式、信息架构文档要求，除非用户明确提出

## 每页必须满足

对每个页面或视图，都要明确包含：

- 页面标题区
- 核心内容块
- 主要操作按钮
- 表单或输入区
- 导航或返回路径
- 加载态
- 空态
- 错误态
- 选中态/展开态/禁用态（如果该页面存在）

## 交互要求

- 导航、切页、筛选、搜索、分页、弹窗、抽屉、地图、播放器、卡片点击等交互都要有完整前端表现
- 表单要有校验反馈
- 按钮需要区分主次级
- 列表和详情之间的关系要清楚
- 移动端和桌面端至少保证布局不坏

## UI polish约束

- 标题和短正文避免难看的孤行、挤压和横向滚动。
- 嵌套圆角遵循视觉关系，外层圆角应考虑内层圆角和间距。
- 图标按钮、箭头、播放按钮等按视觉重心对齐，不只做几何居中。
- 需要深度的卡片、按钮、弹层优先用低透明阴影或ring，不要到处硬描边。
- 图片和截图边缘要在浅色/深色模式下都干净。
- hover、press、focus、disabled、loading、active状态要齐全。
- 交互动画要可中断；退出动画短于入场动画；不要使用过长、夸张或玩具化的动效。
- 动态数字、计数器、价格、仪表盘数值要保持宽度稳定。
- 小图标按钮、checkbox、slider等目标区域要接近40-44px，命中区域不能互相重叠。
