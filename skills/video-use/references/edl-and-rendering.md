# EDL And Rendering

## Minimal EDL Shape

The renderer expects JSON with source files and timeline ranges. Prefer named
sources so transcript files and timeline logs stay readable. Keep paths absolute
when the EDL may be moved; otherwise resolve relative paths from the EDL
directory.

```json
{
  "sources": {
    "intro": "/absolute/path/to/source-a.mp4",
    "demo": "/absolute/path/to/source-b.mov"
  },
  "grade": "auto",
  "ranges": [
    {"source": "intro", "start": 1.2, "end": 8.7},
    {"source": "demo", "start": 12.0, "duration": 5.5}
  ]
}
```

Prefer `start` plus `end` for human review. Use `duration` when generated by a
script or when the end timestamp is less clear. The renderer accepts both
`sources` maps and legacy source lists, but maps are easier to review.

Transcript lookup checks `<source-key>.json` first and then the source file stem.
For example, source key `demo` pointing to `clip-03.mp4` can use either
`edit/transcripts/demo.json` or `edit/transcripts/clip-03.json`.

## Render Commands

Preview:

```bash
python3 scripts/render.py edit/edl.json -o video-use-output/task/preview.mp4 --preview
```

Final with subtitles:

```bash
python3 scripts/render.py edit/edl.json -o video-use-output/task/final.mp4 --build-subtitles
```

Final without subtitles:

```bash
python3 scripts/render.py edit/edl.json -o video-use-output/task/final-clean.mp4 --no-subtitles
```

Run commands from the skill directory or call scripts by absolute path.

## Practical Editing Rules

- Make a draft/preview for complex edits before rendering final output.
- Keep cut points away from half-words unless the style intentionally uses jump
  cuts.
- For speech-heavy videos, align subtitles to transcript word timestamps.
- For vertical social video, confirm caption safe area before final export.
- Preserve source media. Re-render intermediates instead of modifying originals.
- If HDR footage looks overexposed or oversaturated, keep the renderer's HDR to
  SDR tone-mapping behavior enabled.

## Final Checks

Use `ffprobe` to confirm:

- duration is plausible;
- video and audio streams exist when expected;
- resolution/aspect ratio matches the target;
- codec is acceptable for the target platform;
- output size is nonzero and the file opens.

For visual verification, export frames with ffmpeg at the opening, a middle cut,
and the ending, then inspect them before reporting completion.
