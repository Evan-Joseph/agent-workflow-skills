# Communication Anti-Patterns

Use this when a draft sounds wrong but the reason is unclear.

## Low Posture

Signals:

- repeated apologies before any substance
- “占用您宝贵时间”“求求您”“我什么都可以”
- overexplaining weakness before showing facts

Repair:

- keep one respect marker
- state identity, preparation, and request
- let the receiver decline without making the sender smaller

## Fake Praise

Signals:

- generic praise that fits anyone
- praising status instead of specific work, advice, or effort
- exaggerated adjectives without evidence

Repair:

- name one concrete work, sentence, decision, paper, reply, or action
- say why it matters to the current request

## Defensive Disclaimer

Signals:

- “仅供参考”“没有别的意思”“不是想麻烦您”
- long explanation that protects the sender more than it helps the receiver
- preemptively arguing with an objection the receiver has not raised

Repair:

- keep the necessary fact
- remove the self-protective wrapper
- ask for the concrete next action

## Emotional Pressure

Signals:

- making the receiver responsible for the sender’s future, anxiety, grade, job, or relationship
- implying refusal is immoral
- creating urgency without external basis

Repair:

- state the real constraint
- give options and a clean exit
- avoid guilt as the reason to respond

## Manipulative Influence

Signals:

- gifts or favors designed to create debt
- false scarcity, fake consensus, or forced intimacy
- “心理学技巧” used to bypass consent

Repair:

- replace pressure with reason, evidence, and choice
- if providing value, make it genuinely useful and optional

## Vague Ask

Signals:

- “能不能给点建议”“您怎么看我”
- many unrelated questions
- no time, object, document, or decision named

Repair:

- reduce to 1-3 answerable questions
- specify desired output: yes/no, direction, comment, meeting, referral, deadline

## Over-Polished AI Voice

Signals:

- every paragraph has the same rhythm
- formal words hide simple actions
- the message explains its own politeness

Repair:

- shorten
- use concrete nouns and verbs
- after strategy is right, use `shuorenhua` for final naturalization if needed
